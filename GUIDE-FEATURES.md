# Guide — features

> **TL;DR** — a spec names **capabilities** (`features`), a spec chooses **field types**, and an
> **archetype** (`pattern`) decides the shape. Nothing is emitted unless it is in the registry
> with an emitter and a check.

Generated by `kiln guide` from `catalogue/` at 0.22.0. Do not edit this file.

---

## The three layers

| layer | lives in | a spec names it as |
|---|---|---|
| capability | `catalogue/capabilities.json` | `features: ["crud", …]` |
| field type | `catalogue/features/field-*.json` | `entities[].fields[].type` |
| archetype | `catalogue/patterns/*.json` | `pattern: "crud-list"` |

## Capabilities

| id | what it does | requires | the assertion it must satisfy |
|---|---|---|---|
| `a11y` | Accessibility: skip link, focus ring, live regions, reduced motion | — | pressing Tab from the top reaches a skip link before the header buttons |
| `backup` | One-click full backup and restore | export, import | a backup file restored into an empty store reproduces every record |
| `balance` | A running balance per parent, from its children | crud, multi, relation | three movements of +10, -3 and -2 show a balance of 5 on the item |
| `board` | A board of columns from one select field | crud | three records in two stages show two columns, with the counts on the headers |
| `calendar` | A month grid over one date field | crud | a record dated the 13th appears in the cell for the 13th of that month |
| `chart` | Inline sparkline, no library | crud, derived | the sparkline is inline svg with one point per day in the window |
| `comparison` | A fixed-column comparison table with the best value marked | crud | the cheapest price shows a mark, and a row that is not cheapest shows none |
| `convert` | Convert between units of one dimension | — | 1 kilometre converts to 0.62 miles and back again |
| `crud` | Create, read, update, delete | — | creating a record and reloading the page shows the record in the list |
| `dashboard` | A strip of metric cards across one or more entities | crud, multi | two tasks and one note show 2 and 1 on two cards |
| `derived` | Derived metrics: streak, average, goal percent | crud | a tracker with three consecutive days logged shows a streak of 3 |
| `detail` | Read one record in full, without opening the form | crud | clicking a row title opens the record read-only, with its long text as paragraphs |
| `directory` | A search-first directory: one box, cards, no toolbar | crud, search | opening the app puts the cursor in the search box and shows the count, not the rows |
| `export` | Export as JSON and CSV | crud | the export handler produces text that parses as JSON with one row per record |
| `feedback` | Size and backup banners, and a live status region | crud | over 2000 rows the app says so and offers an export |
| `filters` | Facet filters per select or tag field | crud, search | selecting a filter value shows only records carrying that value |
| `formula` | A formula over named inputs, evaluated without eval | — | words 1000 at 200 wpm shows 5.0 minutes |
| `i18n` | Second language toggle | theme | switching language changes at least one rendered label and sets the html lang attribute |
| `import` | Restore from a JSON file | crud | importing a previously exported file restores the same record count |
| `multi` | More than one list in one app, with a switcher | crud | two entities show a switcher, and switching keeps each list's own rows |
| `print` | Print stylesheet | crud | the print stylesheet hides controls and keeps the list |
| `progress` | Progress: how many are done, as a count and a percentage | crud | two of four rows done shows 2 of 4 and 50% |
| `pwa` | Installable, offline manifest | — | the document carries an inline manifest and no external URL |
| `relation` | A field that points at a record in another list | crud, multi | a visit pointing at a patient shows that patient's name, not an id |
| `reminder` | Due dates with an overdue flag | crud | a record with a past due date renders an overdue marker |
| `search` | Search across declared fields | crud | typing a query that no record contains hides every record |
| `sort` | Sort by any column | crud | sorting by a field reorders the rendered list |
| `stats` | Count and summary strip | crud | the summary count equals the number of records rendered |
| `steps` | A form in steps, validated one step at a time | crud | a three step wizard shows Back only from the second step and Save only on the last |
| `tags` | Tag chips on each record | crud | a record saved with two tags shows two chips |
| `theme` | Dark and light theme, remembered | — | toggling the theme and reloading keeps the chosen theme |
| `timeline` | The list grouped by month, newest first | crud | two records in November and one in October show two month headings |
| `toggle` | Toggle a boolean from the row, without opening the form | crud | ticking the box on a row saves immediately and moves the progress bar |
| `totals` | A running total of one numeric field | crud | two entries of 30 and 90 minutes show a total of 2h |

## The rule that keeps this honest

| If you add | You must also add | Enforced by |
|---|---|---|
| a field type to the runtime | a `catalogue/features/field-*.json` with `status: emitted` | guard `C14` |
| a capability | an assertion, a runtime gate, and a row in `PROMPT.md` | `catalog.load()`, guard `B6` |
| an archetype | a descriptor, a sample spec, a screenshot, a pros/cons block | guard `C15` |
