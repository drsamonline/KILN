## What it does when things go wrong

| Situation | Behaviour |
|---|---|
| Bad input | The form refuses to save and names the field |
| No network | Everything keeps working; a note appears saying so |
| Storage full | The change is kept in memory, a banner says it will not survive a reload, export is offered |
| Corrupt saved state | The bad state is copied aside under a `:corrupt:` key, the app resets, and a banner says where the old data went |
