# Code of conduct

**Version** 1.0 · **Effective** 13 November 2026

---

## The short version

Be decent. Assume the other person is competent and busy. Attack the code, not the person.
This project is a tool for making small offline apps; nobody's dignity should be at stake
in a bug report.

---

## What is expected

| Expectation | In practice |
|---|---|
| Plain, kind language | "this fails when the field name has a space" beats "this is broken" |
| Good faith | read the code before concluding the author was careless |
| Patience with a single maintainer | replies may take days |
| Respect for scope | "no" is a complete answer, and it is not a personal judgement |
| Credit where it is due | if someone's idea lands, say so |

## What is not acceptable

| Not acceptable | Examples |
|---|---|
| Harassment | sustained disruption, following someone across threads |
| Personal attacks | insults about skill, intelligence, background |
| Discrimination | on the basis of caste, religion, region, language, gender, sexuality, disability, age or nationality |
| Sexual attention | of any kind, in any space connected to this project |
| Publishing private information | addresses, phone numbers, private messages, health details |
| Deliberate intimidation | threats, or dogpiling on someone |

## Scope

This applies to issues, pull requests, discussions, commit messages, and any space where
someone is representing this project.

## Enforcement

| Step | What happens |
|---|---|
| A report | email sohilmomin2000@gmail.com, or use GitHub's report tool |
| Assessment | the maintainer reads it, and may ask one clarifying question |
| Outcome | a correction, a warning, a comment removed, a temporary block, or a permanent ban |
| Appeal | reply to the same email once; the decision is reviewed and is final |

Reports are handled privately. Retaliation against a reporter is itself a breach.

## Attribution

This document is written for this project rather than copied from a template. It is
deliberately short, because a code of conduct nobody reads protects nobody.
